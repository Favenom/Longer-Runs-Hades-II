# Longer Runs

Hades II mod allowing to increase the number of rooms in Erebus and Oceanus. 

## Features

- Edit the global number of chambers added to every biome.

- Edit the number of chambers added to specific biome.

- Change the number of fountain rooms.

- Allow for multiple minibosses.

- Allows to skip the boss (Default: false)

## Install

- Use r2modman by ebkr from Thunderstore or GitHub.
- It is recomended to create a backup of your Hades II files.
- It is not recomended to install this mod during an ongoing run
  - Nope, not that.

## Usage

- Edit the necessary values in the config editor tab in R2modman
